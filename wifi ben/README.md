## 🌟 نظرة عامة عن المشروع (Overview)

تم تصميم **WiFi Shop Manager** خصيصاً لأصحاب المحلات التجارية، المقاهي، وصالونات الانتظار الذين يرغبون في تقديم خدمة إنترنت مؤقتة لزبائنهم عبر حاسوب يعمل بنظام ويندوز، دون الحاجة لشراء راوترات باهظة الثمن أو برامج اشتراك معقدة.

يتضمن المستودع حالياً **إصدارين متكاملين** لتلبية كافة الاحتياجات:
1. **النسخة الحديثة v2 (الموصى بها):** تعمل بدون صلاحيات مسؤول إدارية إطلاقاً (Zero Admin / No UAC)، وتعتمد على ميزة Mobile Hotspot الرسمية من ويندوز، وتركز على خادم الويب المحلي ومحرك القسائم الديناميكية.
2. **النسخة القديمة v1 (الأرشيف):** محفوظة بالكامل في مجلد `v1_legacy/` لمن يرغب في التحكم اليدوي المباشر في كروت الشبكة وأوامر `netsh` (تتطلب صلاحية مسؤول).

<a name="v2-features"></a>
## ✨ مميزات النسخة الحديثة (v2 - المنطق الجديد للاتصال وتوليد الأكواد)

- **🔒 أمان كامل وتجاوز لنافذة المسؤول (Zero Administrator / UAC Prompts):**
  - يعمل البرنامج بصلاحيات المستخدم العادي بدون ظهور أي نافذة تحذيرية من ويندوز.
- **📡 تحديد اسم شبكة الواي فاي (SSID) وتطبيقها فوراً:**
  - خانة خاصة في البرنامج لتعديل اسم شبكة الواي فاي وحفظها وتطبيقها مباشرة في نقطة اتصال ويندوز (Windows Mobile Hotspot).
- **🔑 الرقم السري الحالي الجاهز للزبون القادم (Current Ready Passcode):**
  - بطاقة بارزة أعلى لوحة التحكم تعرض الكود الرقمي الجاهز المكون من 6 أرقام للزبون القادم.
  - **التوليد التلقائي:** بمجرد أن يستعمل الزبون الكود على هاتفه، يقوم البرنامج تلقائياً بتوليد رقم سري جديد للزبون التالي.
  - **إمكانية التوليد اليدوي:** زر `🎲 توليد كود آخر يدوياً` لإنشاء رقم سري فوري متى رغب صاحب المحل.
  - زر نسخ الرقم وزر طباعة تذكرة إيصال حرارية تتضمن الرقم السري ورمز QR للدخول الفوري.
- **⏱️ تحديد مدة الاتصال للأكواد:**
  - أزرار سريعة لتحديد مدة الكود (15 دقيقة، 30 دقيقة، 1 ساعة، 2 ساعة، أو مدة مخصصة).
- **🎟️ قسم مخصص لتوليد الأكواد حسب المدة (Batch Voucher Generator):**
  - إمكانية توليد دفعات كاملة من الأكواد (كود واحد، 5 أكواد، 10 أكواد، 20 كود) دفعة واحدة حسب المدة والسعر المختار، مع زر لطباعة الدفعة كاملة.
- **📱 تجربة الزبون من الهاتف (بوابة الدخول الذكية):**
  - يفتح الزبون الواي فاي بهاتفه فيظهر له اسم الشبكة المحدد في البرنامج.
  - عند الدخول على الشبكة تفتح له بوابة المحل (`portal.html`) ويطلب منه الرقم السري:
    1. **كتابة يدوية:** خانة مخصصة لكتابة الرقم السري السهل (6 أرقام).
    2. **مسح الباركود / QR كود:** إمكانية مسح كود التذكرة أو شاشة الحاسوب عبر كاميرا الهاتف مباشرة ليتم إدخال الكود وتفعيل الإنترنت فوراً.
- **🛡️ الكود يستعمل لمرة واحدة فقط لكل زبون (Single-Use Policy):**
  - كل كود صالح للاستخدام مرة واحدة فقط لجهاز واحد، ولا يمكن لأي جهاز آخر إعادة استخدام نفس الكود.
- **👥 اتصال عدة زبائن في آن واحد (Multi-Client Simultaneous Sessions):**
  - يمكن لعدد غير محدود من الزبائن الاتصال بالشبكة في نفس الوقت، حيث يحصل كل زبون على حسابه المستقل بعداد تنازلي خاص به يظهر لحظياً في جدول الجلسات النشطة.

<a name="v1-vs-v2"></a>
## ⚖️ مقارنة بين الإصدارين (v1 Legacy vs v2 Server)

| الخاصية | النسخة القديمة (v1_legacy) | النسخة الحديثة (v2_server) |
| :--- | :--- | :--- |
| **صلاحيات المسؤول (UAC)** | ⚠️ مطلوبة إجبارياً (Run as Admin) | 🔒 غير مطلوبة نهائياً (Standard User) |
| **بث نقطة الواي فاي** | أوامر `netsh hostednetwork` و ICS | ميزة ويندوز الرسمية (Mobile Hotspot) |
| **خادم الويب** | خادم خفيف مضمن | خادم HTTP متكامل مع REST API |
| **قاعدة البيانات** | ملف JSON محلي | محرك SQLite مع استعلامات سريعة |
| **الملف التنفيذي** | `WiFiShopManager_v1.exe` | `WiFiShopManager_v2.exe` |
| **المسار في المشروع** | `v1_legacy/` | `v2_server/` |

<a name="quick-start-v2"></a>
## 🚀 التشغيل السريع للنسخة الحديثة (Quick Start - v2)

### الطريقة الأولى: عبر الملف التنفيذي المباشر (الأسهل والأسرع)
1. قم بتشغيل ميزة **نقطة اتصال الهواتف المحمولة (Mobile Hotspot)** من شريط مهام ويندوز أو الإعدادات.
2. انقر نقراً مزدوجاً على:
   ```cmd
   WiFiShopManager_v2.exe
   ```
3. سيفتح البرنامج فوراً في شريط المهام بجانب الساعة (System Tray) ويفتح لوحة التحكم في متصفحك تلقائياً على الرابط:
   `http://localhost:8080/dashboard`

---

### الطريقة الثانية: تشغيل كود Python المصدري
1. افتح موجه الأوامر في مجلد `v2_server/`:
   ```cmd
   cd v2_server
   python app.py
   ```
   أو قم بالنقر المزدوج على ملف:
   ```cmd
   v2_server\start_v2.bat
   ```
2. سيبدأ السيرفر المحلي في الاستماع وتوزيع صفحة الويب للزبائن المتصلين عبر عنوان الـ IP المكتشف تلقائياً.

<a name="building-exe"></a>
## 🔨 بناء وتجميع ملفات EXE محلياً

كلا الإصدارين مزودان بأدوات تجميع ذاتية مدمجة عبر مترجم ويندوز الرسمي (`csc.exe`):
- لتجميع النسخة الحديثة v2:
  ```cmd
  cd v2_server
  build_v2_exe.bat
  ```
  ينتج الملف: `WiFiShopManager_v2.exe` في المجلد الرئيسي.

- لتجميع النسخة القديمة v1:
  ```cmd
  cd v1_legacy
  build_exe.bat
  ```
  ينتج الملف: `WiFiShopManager_v1.exe`.
